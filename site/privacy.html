隐私说明

适用于 wqzachery.dpdns.org 的主页、网盘、AI 助手和聊天室 · 最后更新 2026-10-16

这是吴谦个人维护的小网站，没有广告、没有第三方统计脚本、不设 Cookie。下面列出的就是网站代码实际会保存和转发的全部内容。只有站长（持有后台密钥的人）能查看这些记录。

AI 助手

  • 会保存：你发出的每条消息原文、AI 的回答（含"思考过程"文字和联网搜索的来源链接）、时间、所选模型/思考强度/是否联网、一个随机会话 ID（存在你浏览器里），以及你的 IP 地址和大致位置（Cloudflare 提供的国家和城市）。
  • 会发送给：你选的模型所在的服务商。GPT-6 Astra、Llama、DeepSeek、Qwen、GLM 等由 Cloudflare Workers AI 处理；Nemotron、Laguna、Gemma、North 等免费模型经 OpenRouter 转给对应的模型提供方（如 NVIDIA、Poolside、Google、Cohere），这些免费模型的提供方可能按各自政策保存或使用请求内容。每次会发送最近最多 16 条对话。
  • 联网搜索（开启时）：你的问题会被整理成搜索词（中文问题会先由 Workers AI 翻译成英文），由本站服务器发给 Bing 和 中文维基百科，并抓取前几条结果网页。这些网站看到的是 Cloudflare 服务器，而不是你的 IP。
  • 站长分析：站长可以在后台用 Workers AI 为对话生成标题和摘要，结果和对话一起保存。
  • 限制：每个 IP 同时只能生成一条回答，每天最多 200 次提问；为此会按"IP + 日期"计数，约 7 天后清理。

公共网盘

  • 所有文件对所有访客公开。文件存放在 Hugging Face 的私有数据集里，上传时你的浏览器会直接连接 Hugging Face 的存储服务器（Amazon S3），失败时改由本站服务器中转。
  • 会保存：文件名、大小、上传时间、上传者 IP 和大致位置（国家/省份/城市）。公开列表里只显示由 IP 计算出的一个颜色标记，不显示 IP 本身。
  • 上传额度：为执行每天的额度，会按"IP + 日期"记录上传的大小和数量（约 3 天后清理）。
  • 举报：提交举报时会保存文件、原因、你填写的说明和你的 IP。

聊天室

  • 会保存：昵称、匿名 ID（由你浏览器里的随机密钥计算，不含个人信息）、消息内容、时间和 IP 地址。大厅只保留最近 100 条，每段私信只保留最近 50 条，更早的会自动删除。
  • 私信只有对话双方能在聊天室里看到，但站长在后台可以查看（用于处理骚扰和违规）。

访问统计

  • 打开主页、网盘、AI、聊天页面时，会记录时间、IP、页面、大致位置、设备和浏览器类型（如"Android · Chrome"）、来源网站域名。搜索引擎爬虫不记录。
  • 后台密钥输错时，会把 IP 和错误密钥的哈希保存 15 分钟，用于防止暴力破解。

保存多久、怎么删除

数据保存期限
AI 对话及分析、访问统计、上传记录、举报目前不会自动删除，可联系站长删除
网盘文件不会自动过期；违规文件或站长清理时删除，删除时一并清除它的上传记录和举报
聊天室消息大厅最近 100 条、每段私信最近 50 条
AI 次数计数 / 上传额度 / 密钥错误记录约 7 天 / 约 3 天 / 15 分钟

网站目前没有"删除我的对话"按钮。想删除你的 AI 对话、聊天消息或上传记录，请发邮件给站长（邮箱需要 JavaScript 才能显示），说明大致时间和内容即可。

你的浏览器里存了什么

本站只用浏览器本地存储（localStorage / sessionStorage）保存：AI 会话 ID 和当前对话、模型与思考强度偏好、网盘视图偏好、聊天室匿名密钥和昵称。清除浏览器网站数据即可全部删除。

基础设施

整个网站运行在 Cloudflare 上，所有请求都会经过 Cloudflare 的网络，按 Cloudflare 的政策处理。
